# AI Gateway Android — v0.2

Android-приложение на Kotlin + Jetpack Compose с асинхронной HTTPS-диагностикой популярных AI-сайтов.

## Что реализовано
- Каталог 10 сервисов, поиск и избранное (избранное пока хранится в памяти процесса).
- Проверка всех сайтов параллельно через `Dispatchers.IO` и Kotlin coroutines.
- Тайм-ауты подключения и чтения, HTTPS/TLS, HTTP-коды, время ответа.
- Различение состояний: не проверено, проверяется, ответ получен, ограниченный HTTP-ответ, ошибка соединения.
- Сводка результатов и индикатор прогресса.
- Открытие исходного HTTPS-адреса во внешнем браузере.

## Запуск
1. Установите Android Studio.
2. Распакуйте архив и откройте папку проекта (папка, где находится `settings.gradle.kts`).
3. Дождитесь Gradle Sync; установите Android SDK 35, если IDE предложит.
4. Запустите приложение на устройстве или эмуляторе Android 8.0+.

## Важные технические детали
- Проверка отправляет GET-запрос с `Range: bytes=0-0`; некоторые серверы могут игнорировать Range или отвечать иначе.
- HTTP 401/403/429 и 4xx/5xx показываются как HTTP-ответ/ограничение, а не как доказательство сетевой блокировки.
- Успешный HTTP-ответ подтверждает достижимость endpoint, но не вход, доступность функций или право использования сервиса в конкретном регионе.
- Ошибки DNS, TLS, тайм-аут и прочие IOException отображаются отдельно.
- Нет VPN, прокси, скрытого изменения сетевых настроек или обхода ограничений провайдера.
- Для выпуска APK потребуется собрать и подписать приложение в Android Studio.

## Ограничение тестирования
Код подготовлен как исходный проект, но здесь не запускалась сборка Gradle на Android SDK. Перед публикацией выполните сборку и тесты на целевом устройстве.

## Автоматическая сборка APK через GitHub Actions
1. Создайте репозиторий на GitHub и загрузите в него все файлы проекта, включая скрытую папку `.github/workflows`.
2. Откройте вкладку **Actions** и запустите workflow **Build Android APK** (или отправьте push в ветку `main`/`master`).
3. После успешного завершения откройте запуск workflow и скачайте артефакт `AIGateway-debug-apk`.
4. Распакуйте артефакт и установите `app-debug.apk` на Android. Это debug-сборка для тестирования, не подписанный релиз для Google Play.

Примечание: workflow требует доступного GitHub-репозитория. Сборка в текущем контейнере не выполнялась, поскольку здесь не обнаружены Android SDK и Gradle.
